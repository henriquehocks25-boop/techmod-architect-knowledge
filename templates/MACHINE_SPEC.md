# Template — MACHINE SPEC

[RECOMMENDATION] Preencha este artefato no projeto consumidor. Campos orientam decisões; não constituem configuração nem API verificada.

## Papel

Nome funcional, transformação, estágio de progressão e primeiro uso.

## Recursos

Slots/tanques/buffers, filtros, faces locais e limites por operação.

## Processamento

Duração, custo, startup, catalisadores, subprodutos, chance e saída bloqueada.

## Estados

Idle, running, blocked, paused, fault; regras de troca/cancelamento e retomada.

## Persistência e UX

Dados salvos, caches reconstruídos, feedback por causa e sync por observador.

## Aceite

Entradas insuficientes, falta de energia, dois usuários, unload, save e saída parcialmente cheia.

## Uso

Registre decisões conhecidas; para informação ausente indique responsável, evidência e condição de resolver. Aceite “não sei, me recomende” e proponha defaults explicados em linguagem simples. Consulte o [roteador](../TOPIC_ROUTER.md) para o contexto necessário.
