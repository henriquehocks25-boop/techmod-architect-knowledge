# Template — STORAGE NETWORK SPEC

[RECOMMENDATION] Preencha este artefato no projeto consumidor. Campos orientam decisões; não constituem configuração nem API verificada.

## Contabilidade

Armazenamento físico/lógico, capacidade, tipos, componentes e grandes contagens.

## Dispositivos

Prioridades, partição, disponibilidade, terminal e acesso externo.

## Jobs

Patterns, reservas, dependências, limites de expansão, cancelamento e devolução.

## Rede e segurança

Ownership, permissões, paginação, índices e sync.

## Aceite

Disco removido, dois requests concorrentes, ciclo de receita, overflow e restart.

## Uso

Registre decisões conhecidas; para informação ausente indique responsável, evidência e condição de resolver. Aceite “não sei, me recomende” e proponha defaults explicados em linguagem simples. Consulte o [roteador](../TOPIC_ROUTER.md) para o contexto necessário.
