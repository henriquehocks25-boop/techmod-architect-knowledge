# Orientações desta biblioteca

- Escreva em português; preserve nomes oficiais de API e termos pesquisáveis.
- Consulte TOPIC_ROUTER.md e decisões locais antes de ampliar o escopo.
- Não implemente mods nem altere o plugin nesta biblioteca.
- Separe fatos de versão, observações e recomendações. API concreta exige [VERSION-SPECIFIC], versão e fonte.
- Não copie código nem assets externos. Licenças de código e arte podem diferir.
- Documento de domínio deve ter decisão útil, invariantes, falhas e verificação. Evite repetir conteúdo de outro módulo.
- Atualize o índice, roteador e fontes ao adicionar documentos.
- Execute node scripts/audit.mjs antes de concluir. Reporte limitações sem inventar testes, medições ou compatibilidade.
- Preserve histórico Git; nunca force push.
