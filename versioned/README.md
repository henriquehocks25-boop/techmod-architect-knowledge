# Conhecimento versionado

[RECOMMENDATION] Nenhuma combinação Minecraft/NeoForge foi escolhida como alvo de implementação desta biblioteca.

Só criar minecraft-V/neoforge-N após resolver versões reais. Cada API_NOTES deve registrar assinatura, versão exata, fonte, data e status: documentado, inspeção de fonte ou compilado/testado. VERIFIED_PATTERNS exige teste executado e resultado; consulta de docs sozinha não basta.

MIGRATION_NOTES descreve origem/destino, mudanças de IDs e save, compatibilidade, testes e recuperação. SOURCES registra ref imutável quando código foi inspecionado.

O seletor padrão das docs consultadas mostrou 26.1 em 2026-10-06. Isso não prova que 26.1 é a versão mais recente nem que um mod estudado a suporta. Alguns documentos 1.21.1 também foram consultados e permanecem separados na [política](../knowledge/neoforge/version-policy.md).
