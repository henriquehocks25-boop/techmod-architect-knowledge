# Checklist — ui-ux

[RECOMMENDATION] Revisar projeto/implementação; marcar item somente com evidência. Item não aplicável exige motivo, não aprovação fictícia.

- [ ] Inputs/outputs/catalisadores distinguíveis sem só cor.
- [ ] Barra comunica saldo e requisito com units.
- [ ] Causas de bloqueio mostram ação de recuperação.
- [ ] Side config apresenta orientação local.
- [ ] Viewer opcional ausente mantém fluxo utilizável.
- [ ] Escala/tradução longa e dois usuários testados.

## Evidência mínima

Registrar cenário, versões, comando/passos e resultado. Falha cria TASK de correção com invariante afetado. Conceitos em [documento do domínio](../knowledge/ui-ux/machine-and-network-ux.md).
