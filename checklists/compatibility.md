# Checklist — compatibility

[RECOMMENDATION] Revisar projeto/implementação; marcar item somente com evidência. Item não aplicável exige motivo, não aprovação fictícia.

- [ ] Matriz loader/game/mod versions verificada.
- [ ] Integração opcional ausente não causa class error.
- [ ] Adapter usa API pública e isola imports.
- [ ] Handlers parciais/faces/tags/reload cobertos.
- [ ] Claims/viewers/computadores e pack alvo testados.
- [ ] Licença/transitive/runtime/bundled registrados.

## Evidência mínima

Registrar cenário, versões, comando/passos e resultado. Falha cria TASK de correção com invariante afetado. Conceitos em [documento do domínio](../knowledge/compatibility/adapters-and-contracts.md).
